# v0.9 结项与验收说明

v0.9 面向 `technical` 主题模式，补齐从多来源证据到技术 skill 的可复核闭环。

## 新增能力

- 生成 `topic_package/SKILL.md`，内容只引用已保存的融合结论和 GitHub 公开材料。
- 保留 `topic_package/references/` 下的来源级参考文件。
- 生成 `topic_package/score.json`，包含 documentation、skill、evidence、executability、boundaries 五个维度。
- `skill-gather topic review <run-id> --label usable|needs_changes|unusable` 写入人工复核并保守更新最终状态。
- 失败 run 在 `generating` 或 `scoring` 阶段恢复后，可直接重新生成/评分，不重复抓取来源。
- 已完成 run 可通过 `topic rerun --stage processing_sources|generating|scoring` 定点重跑，并保留 `rerun_audit.json`。

## 离线验收

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests
.\.venv\Scripts\python.exe -m skill_gather --help
```

完成一次 fake 搜索并确认技术来源后，运行：

```powershell
skill-gather topic process <topic-run-id> --runs .\runs --config config.json --vision-mode off
```

检查主题 run 下同时存在 `topic_package/knowledge.md`、`topic_package/fusion.json`、`topic_package/SKILL.md`、`topic_package/score.json` 和 `topic_package/references/`。再执行：

```powershell
skill-gather topic review <topic-run-id> --runs .\runs --label needs_changes --notes "补充边界说明"
```

确认 `score.json.human_review` 已记录，且 `final_status` 为 `needs_review`。

阶段重跑验收：

```powershell
skill-gather topic rerun <topic-run-id> --runs .\runs --stage generating
skill-gather topic process <topic-run-id> --runs .\runs --config config.json --vision-mode off
```

确认 `rerun_audit.json` 新增一条记录，来源证据仍保留，`SKILL.md` 与 `score.json` 已重新生成。
