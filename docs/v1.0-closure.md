# v1.0 结项与验收说明

v1.0 将主题搜索、候选确认、网页/视频/GitHub 处理、证据融合、知识总结、技术 skill、评分、人工复核和阶段重跑收束为本地工作台。对外名称为 `skill_seargen`，兼容保留 Python 包和 CLI 名称 `skill_gather` / `skill-gather`。

## 离线回归

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests
.\.venv\Scripts\python.exe -m skill_gather acceptance --dataset benchmarks/v1.0-topics.json --config configs/skill-gather.example.json --runs .\runs\v1.0-offline-acceptance
```

第二条命令必须输出 `case_count: 10`、`passed_count: 10`、`status: passed` 和 `synthetic: true`。它只验证固定主题集的搜索、候选和审计契约，不是对外部服务的替代证明。

## 真实服务 Smoke Test

前提：配置一个可用的公开 SearXNG 实例；可选配置 `GITHUB_TOKEN`；视频链路还需要 `yt-dlp`、`ffmpeg`、本地 faster-whisper 模型及可用 NewAPI key。不得使用 cookie、登录态、付费内容或绕过访问控制。

```powershell
Copy-Item configs\skill-gather.example.json config.json
# 编辑 config.json，设置 search.searxng_base_url；需要视频/模型阶段时设置 NEWAPI_API_KEY。
.\scripts\dev.cmd
```

浏览器打开控制台显示的本地地址，创建一个技术主题，点击“搜索候选”，手工勾选公开网页和公开 GitHub 仓库后点击“确认选择”和“开始处理已选来源”。验收时检查主题 run 下：

- `topic_package/sources.json` 只包含手工确认的来源；
- `topic_package/evidence/` 保存轻量证据而非完整视频或仓库 clone；
- `topic_package/fusion.json` 保留结论引用、冲突和证据缺口；
- `topic_package/knowledge.md` 存在；技术主题还存在 `SKILL.md`、`references/` 与 `score.json`；
- 失败时存在 `failure_audit.json` 或来源级处理审计，并给出重跑建议。

真实全量测试必须逐个直读这些产物，并把网络、模型、权限或证据完整性阻断保留为 `needs_review` 或 `failed`，不能用离线 fixture 替代。
