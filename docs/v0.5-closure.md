# v0.5 结项说明

结项日期：2026-08-05

v0.5 的目标是让普通模式先可用：用户创建主题、搜索并确认公开网页候选后，可以处理已确认网页，保存可复核证据，并生成中文 `knowledge.md`。

## 已完成范围

- `topic process` 支持处理普通模式中已确认的 `web` 来源。
- 网页抓取仅接受公开 `http/https` URL，不使用 cookie、登录态、token 或浏览器会话。
- 成功网页会写入：
  - `topic_package/evidence/<candidate-id>.json`
  - `topic_package/references/<candidate-id>.txt`
  - `web_processing_audit.json`
- `knowledge.md` 包含摘要、关键要点、步骤或方法、结论分歧、证据不足与处理限制、来源列表，并使用 `S1` 等来源编号引用。
- 抓取失败和非网页来源不会被静默丢弃，会记录到处理审计中。
- `TopicPackage.knowledge` 对旧 run 兼容：处理前缺失时按需补齐；文件不存在时不暴露虚假的 knowledge artifact。

## 不属于 v0.5

- 视频来源处理属于 v0.6。
- GitHub 来源处理属于 v0.7。
- 网页、视频、GitHub 的统一结论融合属于 v0.8。
- 自动评分、最终 skill 生成和 Web 完整工作台属于后续版本。

## 验收方式

CLI 验收：

```powershell
.\.venv\Scripts\python.exe -m skill_gather topic create "家庭烘焙" --mode normal --runs .\runs
.\.venv\Scripts\python.exe -m skill_gather topic search <topic-run-id> --config config.json --runs .\runs --fake
.\.venv\Scripts\python.exe -m skill_gather topic candidates <topic-run-id> --runs .\runs
.\.venv\Scripts\python.exe -m skill_gather topic select <topic-run-id> <web-candidate-id> --runs .\runs
.\.venv\Scripts\python.exe -m skill_gather topic process <topic-run-id> --runs .\runs
.\.venv\Scripts\python.exe -m skill_gather topic inspect <topic-run-id> --runs .\runs
```

应确认：

- 命令输出 `status` 为 `completed`。
- `topic_package/knowledge.md` 存在，且内容为中文总结。
- `topic_package/evidence/` 下存在网页 JSON 证据。
- `topic_package/references/` 下存在网页文本快照。
- `web_processing_audit.json` 中记录成功、失败和跳过来源。

Web 验收：

```powershell
npm run dev
```

访问 `http://127.0.0.1:8765` 后：

- 创建普通主题。
- 使用 fake 搜索或已配置的真实搜索获得候选。
- 勾选网页候选并确认。
- 点击处理已选来源。
- 主题完成后应显示知识总结 artifact，后端 run 目录中应出现 `knowledge.md` 和网页证据文件。
