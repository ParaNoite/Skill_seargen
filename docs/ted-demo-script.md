# Search × Generate 演讲演示脚本

## 核心版（6 分钟）

| 时间 | 画面 | 讲述目标 |
|---|---|---|
| 0:00-0:30 | 首页 `Search × Generate` 全屏 | 用一个教程视频、网页和代码仓库散落在不同位置的场景切入：资料很多，但还不是可执行能力。 |
| 0:30-1:20 | 首页双引擎 | 解释 Search 和 Generate 同等重要：前者扩大证据面，后者把多模态证据压缩成 Skill。 |
| 1:20-2:20 | 浏览 Skills | 展示 12 项货架和“可下载 / 待复核索引”状态，强调目录是结果，不是项目全部。 |
| 2:20-3:00 | 打开“视频证据蒸馏”详情 | 展示用途、证据、风险、来源、许可证，并下载本地演示包。 |
| 3:00-4:20 | 工作台 / 研究 | 展示 Search 轨道：主题计划、视频/网页/GitHub 候选和人工选源。 |
| 4:20-5:25 | 工作台 / 结果 | 展示 Generate 轨道：ASR、视觉理解、融合、评分、待复核状态。 |
| 5:25-6:00 | 返回首页 | 收束观点：Search 让 Generate 有真实材料，Generate 让 Search 得到可执行结果。 |

## 可选扩展（约 2 分钟）

- 解释为什么外部 Skill 只索引、不随意镜像：来源地址不等于再分发许可。
- 展示失败或 `needs_review` 状态，说明系统不会把证据不足包装成“已完成”。
- 展示下载 ZIP 中的 `SKILL.md` 与 `LICENSE`，说明最终交付仍可人工检查。

## 录屏镜头清单

1. 使用 `1920×1080` 浏览器窗口，关闭通知与无关标签页。
2. 首页停留 4 秒，鼠标只划过 Search 与 Generate 两个区域。
3. 点击“浏览 Skills”，筛选“可下载”，打开“视频证据蒸馏”。
4. 缓慢滚动详情中的证据、风险和许可证，点击下载。
5. 进入工作台，依次切换“研究”和“结果”，不要现场触发真实外部任务。
6. 返回首页结束。录制一份完整无剪辑版本和一份按上述时间点剪辑的 45 秒应急版本。
