# v0.2 人工标注准则

标注对象是候选 skill 包，不是视频制作质量。标注者应复核 `SKILL.md`、证据时间线、风险项和时间戳引用，在不知道规则分与 Judge 分的情况下给出结论。

## 标签

- `usable`：核心流程可执行，关键结论均有证据，适用边界和验证方式足以避免明显误用。
- `needs_changes`：主题和主要步骤可复用，但证据引用、边界、风险或测试存在可修正缺口。
- `unusable`：核心步骤不可执行、关键结论无证据、主题不构成可复用技能，或存在不可接受的安全与合规风险。

## 标注流程

1. 先核对候选标题与视频主题是否一致。
2. 逐项检查 Recall、Interpret、Apply、Boundary、Test 是否有内容且能由时间戳证据支持。
3. 检查命令、配置、版本和前置条件是否完整，是否包含视频未给出的推断。
4. 检查风险项是否被候选内容明确处理。
5. 写下标签和简短修改理由；存在分歧时由第二位标注者复核。

## 数据格式

校准文件是 JSON 数组。每项至少包含 `id`、`human_label`、`rule_score`、`judge_score`，可选 `difficulty`。真实基线还应在同一版本记录来源 URL、模型和提示词版本，但不得提交受限媒体或模型原始输出。
