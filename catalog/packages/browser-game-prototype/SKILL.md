# 网页游戏原型

先定义一个可在首屏解释清楚的核心动作，再实现玩家、障碍、得分、失败和重启状态。固定画布或游戏区域的尺寸，使用稳定的输入映射，避免先堆叠装饰而没有可玩的循环。

## 执行步骤

1. 写出开始、进行中、失败、胜利和重启五个状态。
2. 先用几何形状实现角色、障碍和碰撞，再补充视觉资产。
3. 为键盘、指针和触摸输入提供同一组动作。
4. 为每个状态添加可见反馈，并确保刷新页面后能重新开始。
5. 在桌面和窄视口各走一遍完整流程，记录未验证的行为。

## 完成标准

- 页面加载后无需额外配置即可开始。
- 玩家能完成一次成功或失败流程并重启。
- 碰撞、得分和状态变化不依赖隐藏控制台输出。
- 移动端视口没有遮挡主要操作区域。

## 边界

这是原型设计与实现清单，不替代性能分析、无障碍审查或线上部署安全评估。
