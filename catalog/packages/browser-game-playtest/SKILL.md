# 网页游戏真实验收

以普通玩家身份从空白页面开始测试，不用内部变量直接制造结果。桌面和移动视口都必须记录操作、页面状态、截图和控制台错误。

## 验收流程

1. 访问入口并确认主要画布或游戏区域非空。
2. 用键盘、鼠标或触摸完成一次有效输入，确认角色状态发生变化。
3. 触发一次障碍或失败条件，确认失败提示和重启入口出现。
4. 重启后确认状态、得分和障碍恢复到初始条件。
5. 在窄视口重复输入、碰撞和重启，检查文本、按钮与画布不重叠。
6. 保存 Trace、关键截图和浏览器控制台错误；无法验证的项目保持待复核。

## 完成标准

- 桌面和移动流程均有可复查证据。
- 至少覆盖开始、进行中、失败、重启和成功或结束状态。
- 控制台无未解释错误，截图能展示真实游戏画面。

## 边界

该清单不证明游戏逻辑没有漏洞，也不替代不同浏览器、网络条件和辅助技术下的完整兼容性测试。
